# Handoff: scan-identify-hellos — opt-in identify hellos (--identify) and DNS records (--dns-records)

Run scanner-build-2026-11-22, plan_id w3-build. Branch `scanner/identify-hellos`. Lead decisions 10 (hellos as an opt-in family) and the 2026-11-22 follow-up (RDP, SMB, LDAP).

## Discovery → Design
- **Need:** mail STARTTLS was "not checked" for SMTP/POP3 (#114); RTSP/SIP/BMC/camera rows in the catalog need one standard question; mail-domain DNS hygiene (SPF, DMARC, CAA, BIMI, MTA-STS, DKIM) for attested domains; RDP NLA, SMB signing and the LDAP root DSE (lead decision).
- **Constraints:** detection only; one standard unauthenticated client message per service per host; frozen literals; off by default; every exchange through the Limiter (host/total budgets, --max-minutes, Ctrl-C); no new dependencies; tests on loopback only.
- **Standards used (byte layouts):**
  - SMTP EHLO / QUIT: RFC 5321 4.1.1.1, 4.1.1.10; STARTTLS keyword RFC 3207; AUTH keyword RFC 4954 (names only).
  - POP3 CAPA / QUIT: RFC 2449 (STLS RFC 2595, SASL, IMPLEMENTATION).
  - RTSP `OPTIONS * RTSP/1.0`: RFC 2326 10.1.
  - SIP OPTIONS: RFC 3261 11 (Max-Forwards 0, so the request is answered by the target and never forwarded), `rport` RFC 3581 for UDP.
  - mDNS: RFC 6763 section 9 service-type query `PTR _services._dns-sd._udp.local`, sent unicast to the host's UDP 5353 from an ephemeral port (RFC 6762 6.7 legacy unicast: the answer comes back to the sender only). Never multicast.
  - IPMI: DMTF ASF 2.0 RMCP presence ping (`06 00 ff 06 | 00 00 11 be | 80 00 00 00`), pong type 0x40, supported-entities bit 7 = IPMI.
  - RDP: [MS-RDPBCGR] 2.2.1.1 Client X.224 Connection Request (TPKT T.123, X.224 CR, no cookie) + 2.2.1.1.1 RDP_NEG_REQ requestedProtocols = PROTOCOL_SSL|PROTOCOL_HYBRID (0x3); reply 2.2.1.2 RDP_NEG_RSP.selectedProtocol / RDP_NEG_FAILURE.failureCode.
  - SMB: [MS-SMB2] 2.1 direct TCP framing, 2.2.1.2 sync header, 2.2.3 NEGOTIATE (dialects 0x0202, 0x0210, 0x0300, 0x0302; SecurityMode SIGNING_ENABLED; fixed ClientGuid "CyberView-Scannr"); reply 2.2.4 SecurityMode and DialectRevision.
  - LDAP: RFC 4511 4.5.1 SearchRequest (BER, X.690) for the root DSE (RFC 4512 5.1): base "", scope baseObject, neverDerefAliases, sizeLimit 1, timeLimit 10, filter `(objectClass=*)`, attributes supportedLDAPVersion, vendorName, vendorVersion, objectClass; then RFC 4511 4.3 UnbindRequest.
  - DNS: node:dns `Resolver` (system resolver) resolveTxt/resolveCaa only; SPF RFC 7208, DMARC RFC 7489, CAA RFC 8659, BIMI draft (`default._bimi`), MTA-STS RFC 8461 3.1 TXT, DKIM RFC 6376 3.6.2.
  - The byte layouts were written from the public specifications listed above (no external page was fetched during the build); each is decoded field by field in `tests/unit/scanner-hello.test.mjs`.
- **Recommendation:** built (both families), opt-in.

## Design → Implementation
- **CLI:** `--identify` (SMTP EHLO, POP3 CAPA, RTSP OPTIONS on 554/8554, SIP OPTIONS on TCP 5060 when open and UDP 5060 when 5060 is in the port list, unicast mDNS to UDP 5353, RDP on 3389, SMB2 on 445, LDAP on 389 — TCP ones only on ports the probe found open and not implicit TLS); `--identify-bmc` (needs `--identify`) adds the RMCP/ASF ping to UDP 623. `--dns-records DOMAIN[,DOMAIN]` (each must be a host name listed in the scope's targets; refused otherwise, before any query; max 16) and `--dkim-selectors a,b` (max 8; never guessed).
- **Modules:** `scanner/lib/hello.mjs` (owns its sockets: one TCP connect or one UDP datagram per service per host; frozen `HELLO` table; pure parsers; `helloPlan`, `identifyHost`, `helloFindings`), `scanner/lib/dns-records.mjs` (frozen `QUERIES`, `dnsPlanArgs`, `dnsRecords`, `interpret`, `toDnsCsv`).
- **Hooks (small):** `scan.mjs` probeAll `identify` option (after the path rail, each exchange through `lim.acquire`), host field `identify`; `cyberview-scan.mjs` flags, header lines, `report.run.identify`, `report.run.dns_records`, `report.dns`, `dns.csv`, sends merged into `run.network.sends`; `mail-starttls.mjs` uses the EHLO/CAPA answer (new STARTTLS texts `helloListed` / `helloNotListed`).
- **Report:** `hosts[].identify[] = { service, port, proto, state, sent[] (verbs/labels only), read }` — raw replies are never stored; services from hellos are all `guessed` with no version (out of headline counts); observations: smtp-no-starttls, smtp-auth-cleartext, pop3-no-stls, rtsp-answers, sip-answers, mdns-unicast, ipmi-exposed, rdp-no-nla, smb-signing-not-required, ldap-anonymous-rootdse; DNS: spf-missing/-multiple/-pass-all/-neutral-all/-no-all, dmarc-missing/-multiple/-no-policy/-p-none, caa-missing, dkim-weak-key. DKIM keys are not stored (type and bit length only).
- **Safety (security-check section 7, `scripts/lib/scanner-hello-check.mjs`):** hello.mjs is the only new file allowed `net.connect` / dgram (allowlisted in the two existing rules); every request/quit/hex/closeHex is a plain literal; text requests start with EHLO, CAPA or OPTIONS; no line may start with AUTH, USER, PASS, APOP, VRFY, EXPN, MAIL, RCPT, DATA, STARTTLS, STLS, REGISTER, INVITE, DESCRIBE, SETUP, PLAY, AXFR, IXFR, BIND …; SIP needs Max-Forwards 0; binary messages must equal the checker's own reviewed bytes (`REVIEWED_HEX`: mdns, ipmi, rdp, smb, ldap, ldap-close); exactly one `.write(` and one `.send(` in the file, both in a loop-free transport block; no broadcast/multicast; `identifyHost` refuses unless `enabled === true`; only scan.mjs calls it, inside the guard; DNS: TXT and CAA only, frozen reviewed prefixes, no ANY/AXFR/IXFR, only dns-records.mjs may use `Resolver`. Tests prove each rule fires.
- **Tests:** `tests/unit/scanner-hello.test.mjs` (22 tests): exact bytes received by loopback TCP and UDP fixtures for every hello; nothing sent without the flags (probeAll and the CLI); a non-220 SMTP greeting gets nothing; Limiter refusal sends nothing; DNS against a loopback DNS server records exactly the six planned (name, type) queries and none for an unattested name; checker mutation tests.

## Doc text for docs/scanner.md and scanner/README.md (orchestrator to merge)

> **Identify hellos (off by default).** `--identify` sends ONE standard, unauthenticated client message per service and reads the reply's first lines, then closes: SMTP `EHLO cyberview-scanner.invalid` + `QUIT` (STARTTLS, SIZE and AUTH mechanism names are read; never AUTH, MAIL, RCPT, VRFY, EXPN or STARTTLS), POP3 `CAPA` + `QUIT` (never USER, PASS, APOP or STLS), RTSP `OPTIONS *` on 554/8554 (never DESCRIBE, SETUP or PLAY), SIP `OPTIONS` with Max-Forwards 0 on TCP 5060 and, when 5060 is listed, UDP 5060 (never REGISTER or INVITE), one unicast mDNS/DNS-SD query to the host's own UDP 5353 (never multicast), RDP one X.224 Connection Request with a negotiation request on 3389 (reads whether NLA is required; never TLS, CredSSP or a login), SMB one SMB2 NEGOTIATE on 445 (reads the dialect and whether signing is required; never SMB1 or SESSION_SETUP), LDAP one anonymous base-scope root DSE read on 389 for supportedLDAPVersion, vendorName, vendorVersion and objectClass, then unbind (never a bind). `--identify-bmc` adds one RMCP/ASF presence ping to UDP 623 (no IPMI session). Every exchange counts against the same per-host and total budgets and the time limit. Nothing found this way carries a version; it stays out of the headline counts. With `--mail`, mail.csv shows STARTTLS/STLS from the EHLO/CAPA reply instead of "not checked".
>
> **DNS records (off by default).** `--dns-records example.org` (only host names listed in the scope file's targets) asks the system resolver once each for SPF (TXT), DMARC (`_dmarc` TXT), CAA, BIMI (`default._bimi` TXT) and MTA-STS (`_mta-sts` TXT); `--dkim-selectors s1,s2` adds DKIM for the selectors you name (the scanner never guesses selectors). Results go to report.json (`dns`) and dns.csv. Not done: DNSSEC presence (node:dns has no DS/DNSKEY query), the MTA-STS policy file (HTTPS GET not built), zone transfers, ANY, brute force, look-alike names.

Add to the README's "deliberately does not do" list: "send AUTH, USER/PASS, VRFY/EXPN, REGISTER/INVITE, an LDAP bind, SMB SESSION_SETUP, an RDP security exchange, or any multicast/broadcast, even with --identify; transfer zones or guess DKIM selectors".

## Implementation → Review
- **Commits:** 1) original scope (SMTP, POP3, RTSP, SIP, mDNS, IPMI, DNS records); 2) lead decision RDP/SMB/LDAP + this handoff.
- **Not built / open:** DNSSEC DS/DNSKEY presence (node:dns cannot query it); MTA-STS policy HTTPS GET (needs a path-rail Design); SMB dialect 3.1.1 (needs negotiate contexts; the highest offered is 3.0.2, so a 3.1.1-only server answers with an error, recorded); SMTP/POP3 on implicit-TLS ports (465/995) are skipped (EHLO over TLS would need a TLS hello in hello.mjs); RTSP `Allow` reuse from an already-collected header (no RTSP header is collected today); PTZOptics version (none in the row); IPMI OEM enterprise number not mapped to a vendor (no reviewed table).
- **Shared-test edit:** `tests/unit/scanner.test.mjs` line 522 now also skips `hello.mjs` in the "dgram only in udp.mjs" walk — required by the brief's "allowlist the module" rule; flagged for review.
- UDP hellos (mDNS; SIP-UDP when 5060 listed; IPMI with --identify-bmc) go to every in-scope address, like `--udp`, so UDP-only hosts are not missed; each takes a Limiter slot.
